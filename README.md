# AI/ML Task 2 – Feature Engineering, Model Optimization & Performance Comparison

## Objective

To compare multiple machine learning regression models for predicting house prices using the California Housing Dataset.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn

## Models Implemented

1. Linear Regression
2. Ridge Regression
3. Decision Tree Regressor

## Evaluation Metrics

* RMSE (Root Mean Squared Error)
* R² Score

## Project Workflow

* Data Loading
* Feature Engineering
* Feature Scaling
* Train-Test Split
* Model Training
* Model Evaluation
* Performance Comparison
* Visualization

## Outcome

Successfully compared multiple regression models and identified the best-performing model using RMSE and R² Score.
